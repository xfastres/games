# 通用美术提示词前缀

为《边境守望》（Frontier Wardens）制作正式游戏美术资产。游戏使用 Godot 4，类型为 2D 奇幻塔防、领地建设和肉鸽成长，视觉目标是手绘卡通奇幻风格，统一斜俯视等距感。

风格要求：清晰轮廓、适度纹理、木材石材金属材质可辨；光源统一来自左上方；实际游戏尺寸下仍易识别；与提供的参考图保持色彩、线条、透视和材质一致。

技术要求：人物、建筑、投射物、独立特效应输出透明背景 PNG；主体完整，不裁切武器、屋顶、脚部或阴影；不添加文字、水印、边框、网格线或 UI；多帧动画保持角色装备、比例、配色和基准位置一致。请明确说明实际画布尺寸、帧尺寸和排列方式；无法保证时如实说明，不要声称符合。
