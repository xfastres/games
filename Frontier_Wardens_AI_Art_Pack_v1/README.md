# 《边境守望》AI 游戏美术资产包（第一批）

## 本包包含
- `reference/01_asset_overview.png`：整体美术方向与资产类别总览
- `reference/02_asset_style_sheet.png`：建筑、领主、敌人、地形、特效和 UI 的风格参考
- `reference/03_asset_production_board.png`：建议的素材分类、命名和生成顺序
- `prompts/`：可复制的通用提示词与首批资产提示词
- `docs/ART_ASSET_PIPELINE.md`：Godot 4 素材规格、锚点、动画、导入与验收建议
- `assets/asset_manifest.example.json`：后续正式素材清单示例

## 重要说明
这是一份**美术方向参考包 / 生成规范包**，不是已经切割好的可直接投入游戏的生产级透明 PNG 素材库。
参考图中的棋盘格是展示效果的一部分，不能视为真实透明通道；海报上的文字、标签和多个资产也没有被自动拆成独立文件。
正式进 Godot 前，需要逐个生成独立资产，校验透明背景、裁切、尺寸、锚点和动画帧，并在项目中实际测试。

## 建议使用顺序
1. 选定一张参考图作为统一风格参考。
2. 先单独生成弓箭塔、城墙、城堡和领主待机图。
3. 在 Godot 中验证尺寸、接地点、Y 排序与网格占地。
4. 再生成领主行走、攻击、受击、死亡动画。
5. 最后批量生成敌人、地形、特效和 UI 图标。
