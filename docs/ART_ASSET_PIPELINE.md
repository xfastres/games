# 美术素材流程

本文记录《边境守望》当前工程里的素材约定。素材包 B 里的建议尺寸是生成参考，不是这张防守地图的网格规格。

## 当前地图

- 主场景 `scenes/combat/defense_match.tscn` 使用方形网格。
- 正式关卡 `cell_size` 是 64。城堡占 2×2 格，城墙和弓箭塔各占 1×1 格。
- 寻路按格子走，不按图片外接矩形走。
- 图片可以高出格子。绘制时按占地宽度缩放，底边对齐格子底部。
- 素材包里的草地是大小不一致的斜俯视菱形块，没有铺进这张方形关卡。

## 目录

- `assets/sprites/`：准备在游戏里使用或留待下一阶段使用的独立图片。
- `assets/source/art_pack_a/`：素材包 A 的原始副本，包括图集。不要把图集当成地形或角色动画。
- `assets/reference/`：素材包 B 的三张参考海报。它们包含文字和多件素材，不能当作建筑、地形或人物纹理。
- `assets/sprite_manifest.json`：正式图片和源文件的对应关系。

## 引用方式

- 建筑和敌人的可选字段 `sprite` 必须是项目内已存在的 `.png`。缺少文件会在读取配置时失败。
- 没有 `sprite` 时，战斗建筑和敌人继续画原来的色块或圆。
- 城堡、箭矢、命中闪光和顶部金币、生命图标由对应脚本按固定的 `res://` 路径加载。路径失效时会 `push_error`，并退回原来的色块或只保留文字。
- `sprite` 不改变造价、生命、伤害、射程或占地。

## 动画

素材包没有规则排列、帧尺寸一致的 spritesheet。图集上的领主和敌人姿势不能直接当作动画。`assets/sprites/characters/lords/default_lord.png` 只是一张静态图，没有接到场景里。

以后如果要做待机、行走、攻击、受击和死亡，需要单独生成脚底对齐、画布一致的帧，再接入。不要靠复制同一帧冒充动画。

## 导入

图片在绘制节点上使用最近邻过滤。逻辑碰撞不读取纹理尺寸。
